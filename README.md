# omnifind

`omnifind` is an asynchronous Rust crate for metasearch and web-content extraction. It uses [`primp`](https://crates.io/crates/primp) for browser-impersonating HTTP requests and presents normalized result types.

## Sources

- DuckDuckGo web and image search
- Qwant web search
- Wikipedia search
- Open Library book search
- Generic HTML title, text, and link extraction

Public endpoints can change or apply rate limits. Applications should handle partial results and comply with each source's terms, robots policies, and applicable law.

## Quick start

```rust
use omnifind::{Engine, Omnifind, Result};

#[tokio::main]
async fn main() -> Result<()> {
    let client = Omnifind::new()?;
    let results = client
        .metasearch(
            "local large language models",
            &[Engine::DuckDuckGo, Engine::Wikipedia],
            5,
        )
        .await?;

    for result in results {
        println!("[{}] {} — {}", result.source, result.title, result.url);
    }
    Ok(())
}
```

## API overview

- `search(engine, query, limit)` searches one backend.
- `metasearch(query, engines, per_engine)` runs backends concurrently and deduplicates URLs.
- `images(query, limit)` searches DuckDuckGo Images.
- `books(query, limit)` searches Open Library.
- `extract(url)` retrieves a page and extracts its title, readable text, and absolute links.
- `Omnifind::builder()` configures timeouts, proxying, and browser impersonation.

## Testing

```bash
cargo test --all-targets
cargo clippy --all-targets -- -D warnings
cargo test --test live -- --ignored --nocapture
```

The regular test suite is deterministic. Ignored integration tests call public services and may fail because of rate limits, endpoint changes, or network restrictions.
